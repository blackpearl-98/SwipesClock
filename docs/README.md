# SwipeClock website

This is a static GitHub Pages site. To publish it from this repository:

1. Push the repository to GitHub.
2. Open **Settings → Pages** for the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the `/docs` folder, then save.
5. After GitHub finishes publishing, use the displayed Pages URL as the Chrome Web Store privacy policy URL by appending `/privacy.html`.

The landing page is `index.html`; the public privacy policy is `privacy.html`.
